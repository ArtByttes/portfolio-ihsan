# IHSAN — Brand Design System (Video) v1.0

Built from [FOLDER-STRUCTURE.md](./FOLDER-STRUCTURE.md) context and tokens extracted from the portfolio (`styles.css`).

## Palette
| Name | Hex | Use |
|---|---|---|
| Void Black | `#0a0b0e` | Base backgrounds, caption plates |
| Panel | `#12141c` | Lower-third backgrounds |
| Surface | `#191c26` | Cards, end-card fills |
| Text | `#f8fafc` | Primary type |
| Text Secondary | `#94a3b8` | Roles, subtitles |
| Signature Gold | `#c5a059` | Brand accent, CTAs, logo dot |
| Neon Cyan | `#00f2fe` | Highlight captions, accents |

## Typography
- **Syne 700–800** — headlines, name tags, intro/outro titles, logo
- **Plus Jakarta Sans 400–700** — captions, lower-third roles, UI copy
- Eyebrow labels: 11px, letter-spacing .24em, uppercase

## Signature Grade — "Midnight Gold"
Lifted teal shadows, gold highlights, soft film grain (25% opacity), contrast ~1.25 / saturation ~1.35.

## Motion Language
- Easing: `cubic-bezier(0.4, 0, 0.2, 1)`
- Durations: fast 0.2s / normal 0.3s / slow 0.5s
- Lower-thirds slide in from left; end cards fade at 0.5s
